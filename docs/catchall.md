# Add signmysite to any website

Works anywhere you can edit the HTML or add a "custom code / embed" block.

1. Get your line from [signmysite.com](https://signmysite.com) → **Get your widget**:

   ```html
   <script src="https://signmysite.com/w/YOUR_ID.js"></script>
   ```

2. Paste it anywhere in your page — ideally just before `</body>`, but it works
   in the `<head>`, a footer, or any "Custom HTML / Embed / Code" box too.

3. Save and publish. The signmysite badge appears in the bottom-right corner.

That's it. No account on your host, no file to upload, no settings to change.

**Tips**
- Add it once. If you have a shared footer/template, put it there and it shows on every page.
- Move it to another corner: `<script src="…" data-position="bottom-left"></script>`
  (`bottom-right` default, also `top-right`, `top-left`).
- Match your site: `data-theme="light"` or `data-theme="dark"` (`auto` by default).

**If your platform won't let you add code** (e.g. Substack, Medium), you can't embed
the badge — but you still have a profile at `signmysite.com/@you`. Put that link in your bio.
