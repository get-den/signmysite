# Add Den to Blogger

1. Get your line from [den.com](https://den.com) → **Get your widget**:

   ```html
   <script src="https://den.com/w/YOUR_ID.js"></script>
   ```

2. In Blogger: **Layout → Add a Gadget → HTML/JavaScript**.
3. Paste the line, **Save**, then **arrange** the gadget anywhere (position doesn't
   matter — the badge floats in the corner regardless).

View your blog — the badge is bottom-right.

> Prefer editing the theme? **Theme → Edit HTML**, paste before `</body>`, save.
