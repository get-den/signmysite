# Add signmysite to Framer

1. Get your line from [signmysite.com](https://signmysite.com) → **Get your widget**:

   ```html
   <script src="https://signmysite.com/w/YOUR_ID.js"></script>
   ```

2. **Project settings → General → Custom Code**.
3. Paste the line into **End of `<body>` tag**. **Save**.
4. **Publish**.

Open the published site — the badge is bottom-right.

> Note: custom code runs on the **published** site, not in the editor preview, so
> check the live URL.
