# Add Den to Ghost

1. Get your line from [den.com](https://den.com) → **Get your widget**:

   ```html
   <script src="https://den.com/w/YOUR_ID.js"></script>
   ```

2. **Settings → Code injection**.
3. Paste the line into **Site Footer**. **Save**.

The badge appears bottom-right across your whole site. No theme editing needed.
