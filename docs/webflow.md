# Add Den to Webflow

1. Get your line from [den.com](https://den.com) → **Get your widget**:

   ```html
   <script src="https://den.com/w/YOUR_ID.js"></script>
   ```

2. **Site settings → Custom code → Footer code** (before `</body>`).
3. Paste the line. **Save changes**, then **Publish**.

The badge appears bottom-right on every page.

> Tip: for a single page only, use the page's own **Settings → Custom code** instead.
> Custom code requires a paid Site plan.
